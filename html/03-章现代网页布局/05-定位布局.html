🎯 CSS 定位布局核心知识点

position 属性的五种取值 + z-index 层叠

1. position: static（默认定位）

HTML 元素的默认值，元素按照正常文档流排列。top/right/bottom/left 属性对 static 无效。

static 元素
正常排列
position: static; /* 默认值，可省略 */

2. position: relative（相对定位）

元素相对于自己原本的位置进行偏移，不脱离文档流（原来的位置仍被占据）。

relative
top:20 left:30
relative
top:-10 left:-20
position: relative;
top: 20px; /* 向下偏移，负值向上 */
left: 30px; /* 向右偏移，负值向左 */
💡 重点：relative 是绝对定位的"定位祖先"！给父元素设置 relative，子元素的 absolute 就会相对于它定位。

3. position: absolute（绝对定位）

元素脱离文档流，相对于最近的已定位祖先元素（position 不为 static）定位。
如果没有已定位的祖先，则相对于 <html>。

四个角定位

top:20 right:20
bottom:20 left:20
居中定位 ✨
/* 绝对定位 + transform 居中（经典技巧）*/
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
💡 重点：absolute 元素不占文档流空间，父元素高度会塌陷！常用 relative + absolute 组合实现复杂布局。

4. position: fixed（固定定位）

元素相对于浏览器视口（viewport）定位，滚动页面时位置不变。脱离文档流。

👆 看右下角的紫色按钮，它是 fixed 定位，不受父容器限制。

position: fixed;
bottom: 30px;
right: 30px;
z-index: 999;
💡 常见应用：返回顶部按钮、吸底弹窗、侧边客服栏。

5. position: sticky（粘性定位）

综合了 relative 和 fixed 的特性：在阈值内是 relative，达到阈值后变成 fixed。

内容6：否则 sticky 不生效！

内容7：试试把鼠标放进来滚动吧。

position: sticky;
top: 0; /* 距离顶部 0px 时开始吸附 */
⚠️ 注意：父元素不能设置 overflow: hidden，否则 sticky 失效！

6. z-index（层叠顺序）

控制定位元素的覆盖顺序，数值越大越靠上。只对定位元素生效（position 不为 static）。

z-index: 1
z-index: 2
z-index: 3
auto (同层)
.box {
  position: absolute; /* 必须是定位元素 */
  z-index: 10; /* 数字越大越在上层 */
}
💡 层叠上下文：某些属性（如 opacity < 1、transform、filter）也会创建层叠上下文，影响 z-index 行为。

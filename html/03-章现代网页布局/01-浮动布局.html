🌊 浮动布局（Float）完整学习指南

🚢 第一步：认识 float - 基本属性

CSS 的 float 属性可以让元素"浮动"到父容器的左侧或右侧。它最初是为了实现图文环绕效果而设计的。

/* float 的三个常用值 */ float: none; /* 默认值，不浮动 */ float: left; /* 向左浮动 */ float: right; /* 向右浮动 */

⚡ 第二步：浮动元素的核心特性

总结口诀：浮动元素 = 脱离文档流 + 变成行内块（可以设置宽高，又能横向排列）

特性 1：块级元素浮动后，可以设置宽度了

普通块级元素宽度默认 100%，但浮动后宽度可以由内容决定或手动设置。

我是普通块级 div（宽度 100%）
我是浮动后的 div（宽度 150px）
我也是浮动的（宽度 150px）

💡 浮动后 div 不再独占一行，可以设置宽度，多个浮动 div 可以排在同一行。

特性 2：行内元素浮动后，变成块级了

普通行内元素（如 span）不能设置宽高，但浮动后可以了。

普通 span（不能设宽高） 浮动 span（宽100px 高50px） 浮动 span 2

💡 浮动让行内元素"升级"为类似行内块的表现，可以设置 width/height/margin/padding。

特性 3：浮动元素脱离文档流（重点！）

脱离文档流意味着：浮动元素不再占据原来的空间，后面的元素会"顶上来"填补空缺。

浮动元素
我是下面的元素，我顶上来了！

💡 红色 div 浮动后脱离文档流，蓝色 div 就像红色 div 不存在一样，直接顶到了上面。
这就是为什么浮动容易造成布局混乱——脱离文档流 = 元素"飞起来"了。

🕳️ 第三步：浮动的副作用 - 高度塌陷

当父容器内的所有子元素都浮动后，父容器的高度会变成 0！这叫做高度塌陷。

/* 塌陷的原因： 子元素全部 float 后 → 全部脱离文档流 → 父容器内"空无一物" → 高度为 0 */

🧹 第四步：清除浮动的三种常用方法

核心原理：让父容器形成 BFC（块级格式化上下文），或者在浮动元素后面添加一个"清道夫"。

方法 ①：额外标签法（给浮动子元素后面加一个空 div）

在所有浮动元素的最后面，添加一个设置了 clear: both 的空元素。

子1
子2
子3
/* HTML 中手动加一个空 div */ << /span>div> << /span>/div> /* CSS */ div { clear: both; }

优点：简单易懂，浏览器兼容性好
缺点：需要添加无意义的空标签，不够优雅

方法 ②：overflow: hidden（触发父元素 BFC）⭐ 推荐简单场景

给父容器添加 overflow: hidden（或 auto / scroll），触发 BFC 让父容器包裹住浮动子元素。

子1
子2
子3
/* 只需要给父容器加一行 CSS */ .parent { overflow: hidden; } /* 原理：触发 BFC（块级格式化上下文） BFC 的特性之一就是：会包含浮动的子元素 */

优点：写法简洁，不需要额外标签
缺点：overflow 可能导致超出内容被裁剪（比如做下拉菜单时）

方法 ③：万能清除法（双伪元素法）⭐⭐ 推荐通用场景

使用 ::after 伪元素模拟"额外标签法"，不污染 HTML 结构。

子1
子2
子3
/* 万能清除浮动类 - 复制粘贴即可使用 */ .clearfix::before, .clearfix::after { content: ""; display: block; } .clearfix::after { clear: both; } /* 使用方式：给需要清除浮动的父容器加 class="clearfix" */

优点：不污染 HTML，可复用，业界最常用的方案
缺点：写法稍长，但可以复制一份到处用

🎯 我的建议：在你的 CSS 文件顶部定义一个 .clearfix 类，以后所有需要清除浮动的地方，给父容器加个 class 就行了！

📋 浮动布局核心知识总结

float 是什么？

  • 让元素脱离文档流
  • 可以设置 left 或 right
  • 最初用于图文环绕
  • 现在多用于简单布局

什么是高度塌陷？

  • 子元素全部浮动
  • 父容器高度变为 0
  • 背景和边框看不到
  • 布局会一团糟

清除浮动的方法

  • 额外标签法（简单但丑）
  • overflow: hidden（简洁）
  • 双伪元素 ::after（推荐）
  • 记住 .clearfix 类！

浮动的应用场景

  • 图文环绕效果
  • 导航栏 Logo + 菜单
  • 多列卡片布局
  • 左右/三列布局
💡 现代开发提醒：浮动布局在现代 CSS 中已经被 Flexbox 和 Grid 布局大量替代。但 float 仍然是必须掌握的知识：
① 它是 CSS 布局的基础，理解它才能理解文档流
② 图文环绕效果目前仍需用 float 实现
③ 很多老项目还在用浮动布局，维护时需要看懂

1 创建网格 & fr 单位

给父容器设置 display: grid，再用 grid-template-columns 划分列数。 fr（fraction）是"份数"单位，会自动按比例分配剩余空间。

📋 属性速查表
分类 属性 作用
容器属性 display: grid 创建块级网格容器
grid-template-columns / rows 定义列数/行数和尺寸
gap / row-gap / column-gap 设置格子间距
grid-auto-flow 子元素自动排列方向
子项属性 grid-column / grid-row 指定起始线/结束线，实现跨格
grid-area 给子项命名，或简写行列位置
justify-self / align-self 单独控制当前子项对齐
order 改变子项排列顺序（默认 0）
辅助函数 repeat(n, value) 重复书写 n 次 value
minmax(min, max) 限定尺寸的范围
auto-fit / auto-fill 自动创建尽可能多的列/行

10. 实用技巧

10.1 响应式 SVG

不设置固定宽高，或用 width="100%" + preserveAspectRatio 控制缩放方式。

10.2 CSS 控制颜色

给 SVG 元素设置 fill="currentColor"，即可通过 CSS color 属性统一控制颜色。

10.3 SVG 事件

SVG 元素可以像 HTML 元素一样绑定 click、mouseover 等事件。

10.4 data URI 方式使用 SVG

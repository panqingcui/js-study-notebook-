✨ CSS Animation 基本使用

交互式学习 · @keyframes / animation 属性全解析

CSS Animation 让元素可以自动执行动画，无需 JavaScript。核心由两部分组成： @keyframes（定义动画过程中的关键帧状态）和 animation（把动画绑定到元素上并配置参数）。

简写属性 animation: name duration timing-function delay iteration-count direction fill-mode play-state 可一次性设置全部参数，也可以拆分成单独属性分别设置。

1 @keyframes 关键帧

用 @keyframes 动画名 { from {...} to {...} } 或百分比 0% {...} 50% {...} 100% {...} 定义动画。 from 等同 0%，to 等同 100%。中间可以插入任意百分比的关键帧。

A
animation: slideIn 1s ease-out
2 animation-duration 持续时间

animation-duration 定义动画完成一个周期需要多少秒（s）或毫秒（ms）。 默认 0s（不播放）。值越大动画越慢。

B
animation-duration: 0.5s
3 animation-timing-function 时间函数

控制动画的速度曲线。linear 匀速，ease 默认（先慢后快再慢）， ease-in 慢启动，ease-out 慢结束，ease-in-out 慢起慢停， 还可以用 cubic-bezier(x1, y1, x2, y2) 自定义贝塞尔曲线。

C
animation-timing-function: linear
4 animation-iteration-count 播放次数

定义动画播放多少次。可以填具体数字（如 3）或 infinite（无限循环）。

D
animation-iteration-count: 1
5 animation-direction 播放方向

normal 正常方向（0%→100%），reverse 反向（100%→0%）， alternate 奇次正偶次反，alternate-reverse 奇次反偶次正。

E
animation-direction: normal
6 animation-delay 延迟

定义动画开始前等待多久。animation-delay: 2s 表示 2 秒后才开始。 也可以用负值（如 -1s），让动画从中途开始，仿佛已经播放了 1 秒。

F
animation-delay: 0s
7 animation-fill-mode 填充模式

控制动画在开始前和结束后元素的样式。none 默认，动画外不应用关键帧； forwards 结束后保持最后一帧状态；backwards 延迟期间显示第一帧； both 同时具备 forwards 和 backwards 的效果。

G
animation-fill-mode: none
8 animation-play-state 暂停与播放

running 正常播放，paused 暂停。可以通过 JavaScript 或 :hover 动态切换， 实现鼠标悬停暂停效果。

H
animation-play-state: running
9 综合实战 - 呼吸灯

用 transform: scale() 改变大小 + box-shadow 改变光晕， 配合 infinite 和 alternate 方向，实现经典呼吸灯效果。

animation: breathing 2s ease-in-out infinite alternate
10 综合实战 - 打字机

用 max-width 从 0 到内容宽度，配合 overflow: hidden 和 white-space: nowrap 让文字逐字显现。光标闪烁用第二个动画 blink-caret 实现。

Hello, CSS Animation!
animation: typing 3s steps(22, end) forwards, blink-caret 0.75s step-end infinite

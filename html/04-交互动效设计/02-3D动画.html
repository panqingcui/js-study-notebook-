🧊 3D 变换动画

交互式学习 · CSS transform-style / perspective / rotateX / translateZ

CSS 3D 变换让元素可以在三维空间中移动和旋转。要产生真正的 3D 效果，缺一不可： perspective（透视）、transform-style: preserve-3d（保留3D空间）、 以及 rotateX/Y/Z / translateZ 等 3D 函数。

2D 变换函数：translate(x,y) / scale() / rotate() / skew()
3D 变换函数：translate3d(x,y,z) / translateZ(z) / rotateX(angle) / rotateY(angle) / rotateZ(angle) / scale3d() / scaleZ()

1 perspective 透视距离

perspective: 600px 设置观察者距离元素多远，值越小透视效果越强烈（近大远小越夸张）， 值越大越接近 2D 平面。必须设置在父元素上，子元素才有 3D 效果。

当前 perspective: 200px
2 perspective-origin 透视方向

perspective-origin 决定透视从哪个方向看，默认 50% 50%（正中心）。 第一个值水平位置，第二个值垂直位置。改变它就像移动观察者的视角。

B
当前 perspective-origin: 50% 50%
3 rotateX / rotateY / rotateZ 三轴旋转

rotateX(angle) 绕水平轴翻转（类似翻书，正面向上翻起）， rotateY(angle) 绕垂直轴翻转（类似开门，像旋转门）， rotateZ(angle) 绕 Z 轴旋转（和 2D 的 rotate() 完全相同）。

4 translateZ 深度推拉

translateZ(+npx) 让元素靠近观察者（视觉上变大）， translateZ(-npx) 让元素远离观察者（视觉上变小）。 3D 平移还有简写 translate3d(x, y, z)，触发 GPU 加速，性能更好。

translateZ(0px)
5 transform-style: preserve-3d 立方体

transform-style: preserve-3d 是构建 3D 场景的关键属性， 让子元素保留在真正的三维空间中（默认 flat 会把子元素压扁到父元素平面上）。 立方体六个面分别用 translateZ(±55px) 放前后， rotateX/Y(±90deg) 转到上下左右。

6 backface-visibility 背面隐藏

backface-visibility: hidden 让元素翻转到背面时不可见（像扑克牌）。 配合 preserve-3d + rotateY(180deg) 实现两面不同内容的卡片翻转。 若设置为 visible，翻转后会看到镜像文字。

7 组合变换 translate3d + rotate + scale

多个变换函数可以写在同一个 transform 中，空格分隔。 translate3d(x, y, z) 同时设置三轴平移， 浏览器会把它放在独立的 GPU 图层上，性能比分别写 translateX/translateY/translateZ 更好。

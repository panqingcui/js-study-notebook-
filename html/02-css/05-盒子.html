CSS 盒子模型（Box Model）示例

1. 盒子模型结构图

每个HTML元素都可以看作一个盒子，由以下四部分组成：

内容区域
Content
盒子模型从外到内：
■ Margin（外边距）：盒子与其他元素之间的空间，透明
■ Border（边框）：围绕内边距和内容的边框
■ Padding（内边距）：内容与边框之间的空间，背景色会延伸到这里
■ Content（内容）：盒子的实际内容区域

2. 不同边距设置的盒子

标准盒子

margin: 20px（四周相同）

padding: 20px

border: 5px

不同边距

margin: 10px 20px 30px 40px

（上 右 下 左）

border: 3px dashed

margin 和 padding 的简写规则：
• 1个值：四周相同 margin: 20px
• 2个值：上下 左右 margin: 10px 20px
• 3个值：上 左右 下 margin: 10px 20px 30px
• 4个值：上 右 下 左（顺时针） margin: 10px 20px 30px 40px

3. box-sizing 属性对比

box-sizing 决定了 width 和 height 的计算方式：

content-box
box-sizing: content-box（默认）
实际宽度 = width + padding + border
= 200 + 40 + 10 = 250px
border-box
box-sizing: border-box（推荐）
实际宽度 = width（已包含padding和border）
= 200px
尺寸计算示例：
设置：width: 200px; padding: 20px; border: 5px;

content-box（默认值）：
• 内容宽度 = 200px
• 实际总宽度 = 200 + 20×2 + 5×2 = 250px
• 内容区域固定，padding和border会额外增加尺寸

border-box（推荐）：
• 实际总宽度 = 200px（包含padding和border）
• 内容宽度 = 200 - 20×2 - 5×2 = 150px
• 更容易控制布局，现代开发推荐使用
💡 最佳实践：
在项目开始时添加以下代码，让所有元素使用 border-box：
*, *::before, *::after { box-sizing: border-box; }

4. 过渡效果（Transition）

鼠标悬停在盒子上查看过渡动画效果：

缩放+旋转
颜色+圆角
多属性动画
独立控制
/* 单个属性过渡 */
transition: transform 0.3s ease;

/* 多个属性过渡 */
transition: width 0.3s, height 0.3s, background-color 0.5s;

/* 所有属性过渡 */
transition: all 0.4s cubic-bezier(0.68, -0.55, 0.265, 1.55);

/* 缓动函数：ease | linear | ease-in | ease-out | ease-in-out | cubic-bezier() */

6. 背景图片（Background Image）

background-image 的各种使用方式：

background-size: cover
background-size: contain
background-attachment: fixed
多背景叠加
/* 背景图片 */
background-image: url('image.jpg');

/* 背景尺寸 */
background-size: cover; /* 覆盖整个容器，可能裁剪 */
background-size: contain; /* 完整显示，可能留白 */

/* 背景位置 */
background-position: center;

/* 背景重复 */
background-repeat: no-repeat;

/* 多背景叠加 */
background-image:
  url('overlay.png'),
  linear-gradient(135deg, #667eea, #764ba2);

7. 渐变色（Gradient）

CSS 渐变可以用作背景、边框等：

线性渐变
角度渐变 135°
径向渐变
锥形渐变
多色渐变
重复渐变
/* 线性渐变 */
background: linear-gradient(to right, #ff6b6b, #4ecdc4);
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 径向渐变 */
background: radial-gradient(circle, #f093fb 0%, #f5576c 100%);

/* 锥形渐变 */
background: conic-gradient(from 0deg, #ff6b6b, #4ecdc4, #45b7d1);

/* 重复渐变 */
background: repeating-linear-gradient(45deg, #606dbc, #606dbc 10px, #465298 10px, #465298 20px);

8. 渐变文字（Gradient Text）

使用 background-clip: text 实现渐变文字效果：

线性渐变文字
动态渐变文字
径向渐变文字
/* 渐变文字核心代码 */
background: linear-gradient(135deg, #667eea, #764ba2, #f093fb);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
background-clip: text;

/* 动态渐变文字 */
background-size: 200% auto;
animation: gradient-shift 3s linear infinite;

@keyframes gradient-shift {
  0% { background-position: 0% center; }
  100% { background-position: 200% center; }
}

溢出处理（Overflow）

overflow: hidden; 超出内容会被隐藏，不会显示滚动条。
overflow: scroll; 总是显示滚动条，无论内容是否溢出。
overflow: auto; 只在内容溢出时显示滚动条（推荐）。

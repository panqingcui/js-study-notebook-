伪类选择器 特定状态，用户的交互状态或者结构位置第几个，表单伪类（hover, active, focus, visited, link），符号是冒号：

  • 我是一个链接伪类
  • active 鼠标点击元素时触发
  • focus 元素获得焦点时触发
  • visited 已访问链接时触发
  • link 未访问链接时触发

结构伪类选择器 选择元素在文档树中的位置，符号是冒号：

  • :first-child 选择第一个子元素
  • :last-child 选择最后一个子元素
  • :nth-child(2) 选择第2个子元素
  • :nth-child(2n) 选择所有偶数子元素
  • :nth-child(2n+1) 选择所有奇数子元素
  • :nth-child(3n) 选择所有3的倍数子元素
  • :nth-child(3n+1) 选择所有3的倍数子元素，从第1个开始
  • :nth-child(3n+2) 选择所有3的倍数子元素，从第2个开始

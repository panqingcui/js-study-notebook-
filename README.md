## 项目简介

本仓库记录了我学习前端开发过程中的笔记与实验代码，涵盖 HTML、CSS、JavaScript、Vue.js 以及 Web API 等核心技术。每个章节都包含示例代码和注释，方便复习和查阅。

## 目录结构

~~~
js-study-notebook-/
├── html/                    # HTML & CSS 学习笔记
│   ├── 01-html5语义标签/    # HTML5 语义化标签学习
│   ├── 02-css/              # CSS 样式与选择器
│   ├── 03-章现代网页布局/   # Flexbox、Grid 等现代布局技术
│   ├── 04-交互动效设计/     # CSS 动画与交互效果
│   ├── 05-前沿技术拓展/     # 前端前沿技术探索
│   ├── 06-移动网页开发/     # 移动端网页适配与开发
│   └── 07-响应式网页开发/   # 响应式设计实战
├── js基础/                  # JavaScript 基础知识
├── vue/
│   └── vue3_test/           # Vue 3 实验项目
├── webApis/                 # Web API 学习记录
├── .gitignore
└── README.md
~~~

## 运行方式

部分项目包含 `package.json`，可通过以下命令运行：

~~~bash
# 安装依赖
npm install

# 启动开发服务器（如有）
npm run dev
~~~

> 注：部分目录为纯静态 HTML/CSS 练习文件，可直接用浏览器打开 `.html` 文件查看效果。
